Python Projects

This repository contains two beginner-friendly Python projects.

1. Quiz App

- A simple quiz game made using Python.
- Contains multiple-choice questions.
- Checks answers and calculates the final score.
- Displays the quiz result at the end.

File: "project2.py"

2. Stone Paper Scissors Game

- A simple game played against the computer.
- The computer randomly selects stone, paper, or scissors.
- The program checks the winner and updates the score.
- Displays the final result when the game ends.

File: "project1.py"

Technologies Used

- Python
- Random module
- Loops and conditional statements
- Lists and variables
- User input and output

How to Run

1. Install Python on your computer.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Run the Quiz App:
   
   "python project2.py"

5. Run the Stone Paper Scissors Game:
   
   "python project1.py"
